What Sideshow is

Sideshow is a small overlay that sits hidden until you call it up. It shows the events saved in Main Eventer — the event bank — alongside events from your Google Calendar. Each event opens into its details (name, date, time, price, ages, host, location). Click any detail and it is copied to the clipboard, ready to paste into a design, a post, or a message.

The overlay stays on top of other windows, and it stays open until you dismiss it. It never hides on its own when you click away.

Sideshow runs on Windows and Mac. There is also an iOS keyboard in the same project, which is parked — it needs a paid Apple Developer account.

Summoning it

Any of these call the bubble up — or hide it again if it is already showing:

  • Double-tap a key — double-tap Shift by default. You can pick a different key in Settings > Summon.
  • Hotkey — Ctrl+Shift+E by default (on a Mac: Cmd+Shift+E). Change it in Settings > Summon.
  • Mouse gesture — draw a gesture with the mouse, if you have recorded one in Settings > Summon.
  • Long-click — press and hold a mouse button for the length you recorded, if you have set one up in Settings > Summon.
  • Tray icon — click the Sideshow tent icon in the taskbar (Windows) or menu bar (Mac) once to toggle it, or double-click it. Right-click the icon for the menu: Show Sideshow, Sign in, Help, Quit.

The bubble opens where your Position setting says it should — next to the cursor by default. Drag the Event Bank bubble at the top to move it; with Position set to Remember spot, it opens where you left it.

The bubble

The header has four controls, left to right: the gear (opens Settings), the search box, the calendar view toggle, and the close button (hides the bubble).

Event Bank

The first bubble is the Event Bank — the root of the tree. It is also the drag handle for the whole overlay. Clicking it (without dragging) opens or closes the currently focused event.

Events

Each event shows its name in large bold text, then the date and time range, then price, ages, host, and location in a smaller block separated by dots. Click an event to expand it into its value bubbles; click it again to collapse it.

Each value bubble shows one detail. Click it and the detail is copied — a checkmark draws itself and a soft sound plays. The value bubbles are, in order: name, date, time range, price, ages, host, location. Only details the event actually has are shown.

Hiding events

Every event has an eye icon. Click it to hide that event: it stays saved in the bank, but it no longer appears in the bubble, the calendar view, the badge count, or reminders. Click the eye again — in the bubble or in Settings > Events — to show it again.

Search

Type in the search box to filter the events live. It matches name, date, time, price, ages, host, location, and description. If nothing matches, the bubble says “No matching events.”

Hover

The entry under your cursor grows slightly while the others shrink a little, like the macOS Dock. This only applies when Motion is set to Full.

Keyboard shortcuts

Press Esc in the bubble to close it. In the Settings window, Esc closes Settings instead.

Calendar view

The calendar button in the header switches the bubble between the tree list and a month grid. The grid shows every event on the date it happens; events that last more than one day sit on their start date, and events with no date stay in the tree only.

Use the arrows to move between months, or click the month label to jump back to this month. Click an entry on a date and the bubble switches back to the tree with that event's branch open.

Settings window

Click the gear in the bubble header to open Settings in its own window — a normal framed window, 480 by 700, centered on the display with your cursor. While it is open, the bubble stays up beside it as a live preview: change a look, a color, or a size in Settings and the bubble updates right away, no reload.

When you close Settings, the bubble goes back to how it was before you opened it: hidden again if it was hidden, left visible if it was visible.

Settings has six tabs: Position, Appearance, Text, Summon, General, Events. Everything in Settings is optional — summoning, listing events, and clicking to copy all work with everything off or at its defaults.

Position

The Position button cycles through where the bubble opens:

  • Follow cursor (default) — opens next to the pointer, on the display you are using.
  • Top-left / Top-right / Bottom-left / Bottom-right — a fixed corner of the display with the cursor.
  • Center — the middle of the display with the cursor.
  • Remember spot — opens where you last dragged it.

The bubble's height always fits its content, so it never lands far away from the pointer.

Text

Text color sets the overall text color for the bubble, with swatches or a custom color. Leaving it unset uses the automatic ink, picked for readability against your background.

Below that, each field — Name, Date, Time, Price, Ages, Host, Location — has its own Italic, Underline, and Bold toggles plus its own color. Name is bold by default; turning its Bold off drops the title to the global weight.

If several summon methods fire on one action — for example a long hold that also matches the gesture — Sideshow ignores the second one within a short window, so the bubble does not open and immediately close again.

General

Sign in / Sign out. See Signing in.

Sound. Soft bubble and pop sounds when the panel opens, closes, and copies. On by default.

Motion. Full, Reduced, or Off. When you have not chosen, it follows your operating system's reduced-motion preference. Reduced softens the pulse; Off turns the pulse, the open animation, and the hover magnification off.

Reminders. On by default. Sideshow sends a system notification for each event twice: one day before it starts, and one hour before. The badge on the tray icon (and the Mac dock) counts upcoming events. Reminders and the badge work independently — either can be on without the other.

Accent. One color for the copy confirmation and the interface accents. Default follows the platform (blue on Mac, green on Windows), or pick Terracotta, Clay, Gold, Green, Teal, Blue, or Plum. Terracotta is the studio brand color.

Google Calendar. See Google Calendar.

Help. A link to this page.

Events

The Events tab lists every saved event in the bank. Each row has its eye (hide or show it) and, for Main Eventer events, an edit form: name, date, start and end time, price, ages, host, and location. Saving writes the change back to the saved-event bank.

Google Calendar events appear in the list with their eye only — they are read-only here. To change a calendar event, edit it in Google Calendar.

Hidden events stay in the bank and in this list; they are only hidden from the bubble, the calendar view, the badge, and reminders.

Google Calendar

Turn on Google Calendar in Settings > General to show events from your Google Calendars in the bubble, next to the Main Eventer events. A picker appears below the toggle: tick the calendars you want, each shown with its color dot and “(primary)” on your main calendar.

How it works:

  • Sideshow reads your calendars at most every 5 minutes — when the bubble opens if the last check is stale, and immediately when you change the toggle or your selection. It never polls in the background.
  • If a calendar event matches a Main Eventer event — same title, same date, same start time — the Main Eventer record wins, so you never see the same event twice. The Main Eventer record is the one that carries price, ages, and host.
  • Price, ages, and host are only read from a calendar event's description when it carries the exact lines Main Eventer writes when it pushes an event to Google.
  • Signing in again is required before calendar events appear: the sign-in asks Google for read-only calendar access as well as your account.

Signing in

Sign in with Google in Settings > General, or from the tray menu. The sign-in opens in your system browser and comes back to Sideshow on its own.

Only three Google accounts can sign in: Kyle's, Rochelle's, and the studio's media account (media@firedartsstudio.com). Signing in with any other account shows “That Google account is not on the studio list.”

On Windows, the first sign-in shows Google's unverified-app warning, because the app is not verified with Google yet. Click Advanced, then Go to project-369187068047 (unsafe), then Continue.

Signing out removes the saved sign-in from the app.

Reminders, sound, motion

See General: Reminders are on by default (notifications one day and one hour before each event), Sound is on by default, and Motion follows your operating system unless you pick Full, Reduced, or Off.

Installing & updating

Windows

Download the installer (Sideshow.Setup.<version>.exe) from the Sideshow releases page and run it. Quit Sideshow completely before installing or updating — Windows locks the app's files while it is running, so an install over a running copy will fail. The portable zip (Sideshow-win32-x64.zip) needs no install: unzip it and run Sideshow.exe.

Mac

Download Sideshow-mac-x64.zip from the releases page, unzip it, and drag Sideshow to Applications. The first time, Control-click Sideshow, choose Open, then Open again — macOS blocks apps from outside the App Store on a plain double-click. After that, double-clicking works. Sideshow lives in the menu bar; it has no dock icon.

Linux

Download Sideshow-linux-x64.zip from the releases page, unzip it, and run the Sideshow executable.

Troubleshooting

The bubble does not appear

Check the tray icon is there — the tent in the taskbar (Windows) or menu bar (Mac). Click it once to toggle the bubble. If the app is not running at all, start it from the Start menu, Applications, or the unzipped folder.

“Sign in again to allow Calendar access.”

Your saved sign-in predates calendar access. Sign out, then sign in again — the new sign-in asks Google for read-only calendar access.

Calendar events do not show

Check the Google Calendar toggle is on in Settings > General, and that the right calendar is ticked in the picker below it. The Fired Arts workshops live on the “Admin-Fired Arts Studio” calendar.

“That Google account is not on the studio list.”

Only the three studio accounts can sign in. Switch to Kyle's, Rochelle's, or the media account.

“Sign-in failed.”

The sign-in did not complete. Try again, and check the browser window that opened — the sign-in happens there, and closing it early cancels it.
